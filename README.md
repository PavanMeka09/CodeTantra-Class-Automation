# CodeTantra Class Automation

A simple script to automate joining CodeTantra classes. This tool handles login, monitors for active sessions, and joins them automatically.

## Requirements

Ensure you have Python installed on your system.

### Installation

Install the necessary dependencies using pip:

```bash
pip install -r requirements.txt
```

## Setup

1. Open the `config.py` file in your project directory.
2. Edit the file with your specific credentials and settings (Username, Password, etc.).
3. Save the changes.

## Usage

To start the automation, run the main script:

```bash
python main.py
```

The script will now monitor your account and join classes as they become available.
